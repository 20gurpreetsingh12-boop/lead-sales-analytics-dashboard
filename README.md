# Lead & Sales Analytics Dashboard

A responsive lead management and sales analytics dashboard built with React.js, JavaScript, and Bootstrap.

## 🚀 Features

- Responsive dashboard UI
- Lead management
- Create, update and delete leads
- Search leads by name, company, and sales representative
- Filter leads by status
- Dynamic lead metrics
- Reusable React components
- Controlled forms
- Responsive Bootstrap layout
- Lead value and sales representative tracking

## 🛠️ Tech Stack

- React.js
- JavaScript
- Bootstrap
- Bootstrap Icons
- CSS
- Vite
